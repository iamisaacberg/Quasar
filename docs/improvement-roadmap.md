## P0 — Make status and validation consistent

The application now uses county sources; fictional-site, what-if, route and notification endpoints are retired. Hosted access is public and separate from the optional local Wi-Fi gate. Real-data preparation, portable model/assessment production and unknown-preserving exposure display already exist. Do not repeat the old producer-missing, synthetic-notification or passphrase-gate work as current tasks.

This implementation adds exact-window catalogs and dry-run 25-position batch production, producer-hash transfer checking, all-parcel cross-host comparison, saved-model arithmetic/identity verification and optional county NWS ingestion with distinct failure states. Those software changes do not prove actual data transfer, host activation or a complete replay release.

2. Run read-only saved-model verification. Preserve weak groups and the retained held-out ledger.
3. With authorized host access, run the existing single-window producer and R4–R7 benchmark on actual s390x; compare every parcel against the recorded local assessment.
4. Review and authorize the concrete activation candidate/rollback, then verify source, proxy, API and actual selected parcel/hour agree.
5. Isaac completes visual, keyboard, mobile, missing-source and source-time acceptance. Keep source rainfall reports distinct from model output.
6. Produce the 25-window release only if its real data/disk/resource evidence supports it. Missing source windows stay unknown. Catalog code alone is not full coverage.
7. Use the claim ledger and recording outline with only actual evidence. Recording and submission remain separate; this task excluded submission administration.

See [operations](datathon-submission/operations.md) for commands and reviewable candidate settings. Source paths and hashes are documented, but ignored files are absent in this checkout. A source link is not a transferred artifact.

Contacts, real notifications, shelters and navigation remain separate projects requiring explicit authorization.
